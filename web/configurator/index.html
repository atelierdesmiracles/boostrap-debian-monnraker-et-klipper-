Préparez votre printer.cfg

Renseignez les paramètres que vous connaissez, vérifiez les champs et exportez un fichier de départ. Les broches et paramètres matériels ne sont jamais inventés.

Important : ce configurateur génère un brouillon. Vérifiez le câblage, les broches et les limites mécaniques dans la documentation de votre carte avant de l’utiliser. Il ne pousse pas encore la configuration vers Moonraker.
